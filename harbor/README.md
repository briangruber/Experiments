# Port Cinder

A stylized harbor sailing prototype — clear turquoise lagoon, timber-framed
port town, green-capped sea cliffs, and a little white motorboat with a green
beanie at the tiller.

## Run

```bash
# from repo root
npx --yes serve harbor -p 4173
# open http://localhost:4173
```

Or any static file server pointed at `harbor/`.

## Controls

| | |
|---|---|
| `W` / `S` | throttle / reverse |
| `A` / `D` | steer |
| `Shift` / `Space` | boost |
| drag | look around |
| scroll | zoom chase cam |

On touch: left thumb steers and throttles, right thumb looks.
